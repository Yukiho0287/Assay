# Assay

LLM 渠道检测平台：参数化（base_url + model + 定价）即可对任意 LLM 供应商执行检测，输出评分板与可审计的证据链报告。

## 技术栈

- **前端**：React + TypeScript + shadcn/ui
- **后端**：Go

## 检测架构：三层金字塔

1. **自洽性测试**（零对照、零成本）：验证供应商上报数据与数学约束的一致性——prompt_tokens 确定性、纯 ASCII token/字符上限、边际分词率恒定、缓存记账自洽等
2. **对照测试**：与官方端点 / 第三方独立端点做增量对比，覆盖参数校验面、功能面与错误指纹
3. **质量统计**（可选）：小样本 benchmark 做概率性推断，识别重度量化或模型替换

## 状态

立项阶段，架构设计中。
