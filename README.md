# Assay

LLM 渠道检测平台：参数化（base_url + model + 定价）即可对任意 LLM 供应商执行检测，输出评分板与可审计的证据链报告。

## 检测模型

基本单元是可组合的**检测项（probe）**：每个检测项独立注册、带成本等级与适用条件元数据，检测套件由检测项自由组合。内置检测项按标签分组：

- **自洽性**（零对照、零成本）：验证供应商上报数据与数学约束的一致性——prompt_tokens 确定性、纯 ASCII token/字符上限、边际分词率恒定、缓存计量自洽等
- **对照**：与官方端点 / 第三方独立端点做增量对比，覆盖参数校验面、功能面与错误指纹
- **质量统计**（烧钱、可选）：小样本 benchmark 做概率性推断，识别重度量化或模型替换
